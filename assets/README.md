# Theme assets

`themes/palettes.json` contains compact presets inspired by the named color
schemes. These are not redistributed GTK themes, logos or official theme packs.

The 32 wallpaper PNGs are original deterministic artwork generated by
`scripts/generate-wallpapers.py`, at the PocketTerm35's native 640×480 resolution.
The wallpaper artwork is dedicated to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

No stock-image download, attribution requirement, network wallpaper service or
animated background is involved. The generator uses only Python's standard
library. Each wallpaper can be selected independently of the UI palette.
